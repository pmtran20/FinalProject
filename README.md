# FinalProject
for ITSE-2321-201

This project is a Task manager that keeps track of things to do and if they are completed or not. This would help solve productivity problems with the user.
This program provides a menu driven interface to add, view, and complete task. When the user exits the program the "task" are saved to local .txt files, and the next time the program loads, it would launch with the previous mentioned "task" that the user inputed(File persistence). The ArrayList is used to store pending task that the user has inputed. This was used for the task because ArrayList are dynamic, meaning they can be easily added or removed at any point of time. When the user adds a new task, it is stored in "pendindTasks" ArrayList. When a task is completed from the ArrayList, it would be sent to an Array, which is used to store task. The recursive input validation checks if the user has inputed correct options. This simplifies the logic for the program to prompt the user again until the user inputs the correct integer or option. This removes the need for complex loop situations. Try-catch that was used in this program prevents the program from crashing by just showing an error message instead.
